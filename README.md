# 🚀 FocoFinance

Bem-vindo ao repositório oficial de lançamentos (Releases) do **FocoFinance**! 

Este espaço é dedicado exclusivamente à hospedagem e distribuição das versões do aplicativo para Android (.apk).

## 📱 Sobre o Aplicativo
O FocoFinance é um aplicativo mobile focado em gestão financeira, desenhado para ser rápido, seguro e direto ao ponto. Ele ajuda você a manter o controle total sobre suas finanças e oferece recursos exclusivos, incluindo uma seção de acompanhamento conjunto financeiro para casais.

## 📥 Como baixar e instalar
Para instalar a versão mais recente no seu celular Android, siga os passos abaixo:

1. Acesse a aba **[Releases](https://github.com/PauloRicardoo/focofinance-app-releases/releases)** na lateral direita deste repositório (ou no topo, se estiver no celular).
2. Clique na versão mais recente (ex: `v1.0`).
3. Na seção **Assets**, clique no arquivo terminando em `.apk` (ex: `focofinance-v1.0.apk`) para fazer o download.
4. Após baixar, abra o arquivo no seu celular.
5. Se o Android solicitar, permita a instalação de aplicativos de fontes desconhecidas nas configurações do seu aparelho.
6. Aguarde a instalação concluir e abra o FocoFinance!
